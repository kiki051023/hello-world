学生管理系统（Student Management System）
技术栈：Spring Boot 3.2.5 / Spring Security 6 / MyBatis-Plus / MySQL 8.0 / Redis 7 / JWT / Vue 3.4 / Pinia / Element Plus / Vite / ECharts / Docker
角色：独立开发

架构与业务覆盖
面向院校学生全生命周期管理平台，设计并落地前后端分离架构（Controller→Service→Mapper 分层，统一返回与分页封装），覆盖学生、班级、课程、成绩、教务、学工、实习就业等业务；后端约 302 个 Java 文件、29 个 Controller、100+ 接口，前端 19 个 API 模块、40+ 视图。

权限与安全体系
基于 Spring Security 6 + JWT 实现访问/刷新双令牌机制，并通过 Redis 黑名单支持令牌即时吊销；设计 RBAC 多角色权限模型与行级数据权限隔离，通过 DataScopeFilter 按学校/系部/班级维度过滤数据，保证学生端仅可见本人数据。

核心业务状态机
实现成绩录入→审核→作废的状态机全链路流转，配套变更日志记录，并通过 ECharts 完成多维度成绩分析，支撑教学侧的数据查看与决策。

可观测性与稳定性
设计 traceId 全链路审计，便于问题定位与请求追踪；实现接口限流切面控制访问频率；基于数据库 cron 实现动态定时任务，并通过跨实例锁避免多实例重复执行。

对外接口与交付
设计 OpenAPI v1 外部接口，通过 X-Client-Id 标识调用方，结合幂等键与限流保障接口可靠性；产出 Docker Compose 一键部署方案，编排 MySQL / Redis / 后端 / 前端服务。

数据层设计
完成 37 张核心表与 37 个实体映射设计，SQL 采用 phase1~15+ 版本化迁移管理，并编写结构测试校验迁移结果。

校园二手交易平台
技术栈：Spring Boot / MySQL / Redis / Vue 3
角色：独立开发

核心功能
实现商品发布、分类检索、收藏、下单、订单状态流转和个人中心等功能，并通过角色权限区分普通用户与管理员操作。

并发控制
针对"一件商品只能出售一次"的场景，使用事务与条件更新控制并发下单，避免重复成交。

缓存优化
为热门商品列表增加 Redis 缓存，降低重复查询对数据库的压力。

工程化处理
完成图片上传、分页查询和多条件筛选，统一接口返回结构与异常处理，提升前后端联调效率。
